# Conociendo el proceso — Capacitación AC

Instrumento de capacitación 3D: el recorrido completo de fabricación del tarro de conserva de 3 piezas —desde la bobina de hojalata hasta la prueba de hermeticidad— en 12 etapas navegables.

Publicado con GitHub Pages: https://luhvanir.github.io/acarra-3d/

La versión anterior (v14 «TARRO 3P») quedó archivada en `anteriores/index-tarro3p-v14.html`; no se publica.
